# RK Promoters - Premium Real Estate Website

A modern, premium real estate website for **RK Promoters**, featuring smooth animations, luxury design, and responsive layout.

## Features

- Premium hero section with background slider and parallax effects
- Ongoing & Upcoming project listings with detail pages
- Amenities carousel with unique hover effects per card
- Site plan & site view photo galleries
- Testimonial carousel with auto-scroll
- Contact form with enquiry modal
- Google Maps integration for project locations
- Scroll-triggered reveal animations
- 3D tilt effects on cards
- Glassmorphism navbar with smooth transitions
- Fully responsive design (mobile, tablet, desktop)

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, animations, gradients, glassmorphism
- **JavaScript (ES6+)** - Intersection Observer, dynamic content, carousels
- **Font Awesome** - Icon library
- **Google Fonts** - Playfair Display, Inter, DM Sans

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/rk-promoters-website.git
   ```

2. Open `index.html` in your browser, or use any local server:
   ```bash
   # Using Python
   python -m http.server 8080

   # Using Node.js
   npx serve .
   ```

3. Visit `http://localhost:8080`
